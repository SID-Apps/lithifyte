# app.lithifyte.com — crawler policy
#
# This host serves the application itself. The application is a 900KB
# JavaScript surface behind a sign-in prompt: it is the product, but it is not
# a document, and indexing it only puts a thin page in front of searchers who
# wanted an answer. So the app shell and the sample are kept out of the index
# and every content query is left to lithifyte.com, which has the prose.
#
# The written tutorial IS a document, so it stays crawlable.
#
# ⚠ Cloudflare's "Managed robots.txt" prepends a Google-Extended Disallow to
# this file. Gemini uses that token for grounding. Turn the setting off under
# Cloudflare → lithifyte.com zone → AI Crawl Control → Managed robots.txt.

# ── Content signals (spec: contentsignals.org) ─────────────────────────────
User-agent: *
Content-Signal: search=yes, ai-input=yes, ai-train=no
Allow: /tutorial
Allow: /docs/
Disallow: /$
Disallow: /index.html
Disallow: /demo
Disallow: /demo.html
