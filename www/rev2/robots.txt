# lithifyte.com — crawler policy
#
# Position, stated once: search engines and AI answer engines are welcome to
# read this site and quote it. Training crawlers are not. Being findable and
# being training data are different things, and this file separates them.
#
# ⚠ Cloudflare's "Managed robots.txt" PREPENDS a block that Disallows
# Google-Extended. That token is how Gemini decides whether it may ground an
# answer on this site — not a training-only crawler. If the live file at
# https://lithifyte.com/robots.txt still contains a Cloudflare Managed block,
# turn the setting off: Cloudflare → lithifyte.com → AI Crawl Control →
# Managed robots.txt. Until it is off, Gemini will keep saying the site is
# private or unindexed even though Googlebot is allowed.

# ── Content signals (spec: contentsignals.org) ─────────────────────────────
# search   — building a search index and returning links and short excerpts
# ai-input — using content to ground a generative answer, with attribution
# ai-train — training or fine-tuning a model
#
# ANY RESTRICTION EXPRESSED HERE IS AN EXPRESS RESERVATION OF RIGHTS UNDER
# ARTICLE 4 OF EU DIRECTIVE 2019/790 ON COPYRIGHT IN THE DIGITAL SINGLE MARKET.
