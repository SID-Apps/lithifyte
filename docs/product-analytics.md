# Product analytics (hosted only)

On [app.lithifyte.com](https://app.lithifyte.com) we record **identity** (the email you sign in with) and **allowlisted product events** — section names, “CSV uploaded”, never amounts or merchants.

Self-hosted and `file://` builds send nothing. There is no analytics code path that runs off our host.

The event list and the privacy model are in the [privacy policy](https://lithifyte.com/privacy) and [security and privacy](https://lithifyte.com/security-and-privacy). Operator endpoints are not documented in this public repository.
